# Часть 2. CLI-утилита препроцессинга данных

## Запуск

```bash
cd part2_prepare
python -m app.cli prepare --path ../data/input --ext png,csv --output ../data/output/dataset.npy
python -m app.cli doctor
```

## Команды

- `prepare` — рекурсивно обходит каталог (`pathlib.Path.rglob`), находит файлы с
  указанными расширениями, изображения читает через Pillow (приводит к единому размеру,
  нормализует делением на 255), CSV читает как таблицы (числовые столбцы), объединяет
  всё в один массив NumPy и сохраняет в файл `.npy`. Выводит статистику: число файлов,
  по типам, форму итоговой матрицы, время обработки.
- `doctor` — проверяет версию Python, наличие библиотек (numpy, PIL, pandas,
  matplotlib, dotenv), доступность `nvidia-smi` и `git` через `subprocess.run`,
  печатает рабочую директорию.

## Настройка

Все параметры берутся из переменных окружения (`DATA_DIR`, `OUTPUT_DIR`, `LOG_LEVEL`,
`LOG_FILE`, `IMAGE_SIZE`), аргументов командной строки или значений по умолчанию
(см. `.env.example` в корне проекта). Загрузка `.env` — через python-dotenv.

## Устройство модулей

- `cli.py` — разбор аргументов (argparse), подкоманды prepare и doctor.
- `scanner.py` — обход каталога, чтение изображений и CSV, нормализация, сохранение.
- `config.py` — чтение настроек из окружения с значениями по умолчанию.
- `logging_config.py` — настройка журнала (консоль и файл logs/app.log).
