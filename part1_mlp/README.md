# Часть 1. ООП-реализация многослойного перцептрона

## Запуск

```bash
cd part1_mlp
python -m app.main
```

## Меню

1. Создать сеть (размеры слоёв и функция активации: sigmoid или relu).
2. Загрузить данные из CSV (первая строка — заголовки, последний столбец — ответ).
3. Обучить сеть (эпохи, скорость обучения, размер батча).
4. Предсказание для примера, введённого вручную.
5. Сохранить или загрузить веса в JSON.
6. График ошибки обучения (сохраняется в loss_history.png).
7. Выход.

## Тестовый запуск

В `data/input/test_data.csv` лежит синтетическая выборка (3 признака, бинарный ответ).
Пример сеанса: создать сеть `3 6 1` с активацией sigmoid, загрузить данные,
обучить 300 эпох со скоростью 0.5 и батчем 8. Ожидаемая точность на тестовой части —
около 95%.

## Устройство модулей

- `models.py` — класс `NeuralNetwork`: прямое распространение, обратное распространение
  ошибки (среднеквадратичная ошибка, градиентный спуск), обучение на батчах,
  сохранение и загрузка весов.
- `manager.py` — класс `DatasetManager`: чтение CSV, нормализация (standard или minmax),
  деление на train/test с перемешиванием.
- `exceptions.py` — пользовательские исключения: `InvalidLayerSizeError`,
  `MismatchedDataError`, `DataLoadingError`, `FileOperationError`, `InputValidationError`.
- `utils.py` — график ошибки и функции безопасного ввода.
